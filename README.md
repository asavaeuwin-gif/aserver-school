# 🛡️ CyberEdu Portal

A secure school management platform built with **PHP, MySQL, HTML, CSS, and JavaScript**.

## 📌 Overview

CyberEdu Portal is a multi-role school management system designed for schools, teachers, students, parents, and administrators.  
It includes academic management, communication tools, attendance tracking, report cards, analytics, and cybersecurity features.

## 🚀 Main Features

- Admin, Teacher, Student, and Parent portals
- Secure login system
- Password hashing
- Brute-force login protection
- Activity logs
- Student results management
- GPA and average marks
- Attendance tracking with percentage
- Timetable management
- Announcements
- Internal messaging system
- Parent portal
- Report card printing
- Dashboard analytics
- Dark cyber-themed UI

## 🔐 Security Features

- Role-based access control
- Hashed passwords
- Account lockout after failed login attempts
- Activity logging
- Session protection
- Restricted dashboards by user role

## 🧰 Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP
